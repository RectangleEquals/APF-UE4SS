# AP Framework Multiworld Setup Guide

## Overview

This guide explains how to set up your AP Framework-enabled game for Archipelago Multiworld randomization.

## Prerequisites

1. **Archipelago Installation**: Download and install Archipelago from [archipelago.gg](https://archipelago.gg)
2. **UE4SS**: Your game must have UE4SS installed with the AP Framework mod
3. **Game with AP Framework Mod**: A game running the APFrameworkMod and at least one client mod

## Step 1: Generate Your YAML

The AP Framework automatically generates a ready-to-use YAML file when you launch your game.

1. Launch your game with APFrameworkMod installed
2. The framework will automatically generate `AP_<slot>.yaml` in the mod's `output` folder
3. Copy this YAML file to Archipelago's `Players` directory

The generated YAML contains:
- Base64-encoded capabilities data (items, locations, checksum)
- Default option values from the framework's templates
- Your player name from the framework config

## Step 2: Customize Options (Optional)

You can edit the generated YAML before generation. The default options look like:

```yaml
# Generated by AP Framework
# Modify options below, then provide this file to Archipelago for generation

description: Player1
name: Player1
game: APFramework

requires:
  version: 0.6.5

APFramework:
  capabilities_data: "<base64 encoded data - do not edit>"
  filler_item_weight: 5
  trap_item_chance: 10
```

Available options:
- **filler_item_weight** (1-10): Weight multiplier for filler items
- **trap_item_chance** (0-100): Percentage chance for filler items to become traps

Do NOT edit the `capabilities_data` field - it contains the encoded item/location definitions and checksum.

## Step 3: Generate the Multiworld

1. Open Archipelago Launcher
2. Click "Generate"
3. Select your YAML file(s)
4. Click "Generate Game"
5. The output will be in the `output` folder

You can also use the web generator at [archipelago.gg/generate](https://archipelago.gg/generate) by uploading your YAML file.

## Step 4: Connect Your Game

1. Start the Archipelago server with your generated multiworld
2. Launch your game
3. The APFrameworkMod will automatically connect to the server
4. Start playing!

## Troubleshooting

### "capabilities_data is required"

Make sure you're using the YAML file generated by the framework (from the mod's `output` folder), not an older YAML format.

### "Checksum mismatch"

Your game's mods have changed since generating the multiworld. Regenerate by:
1. Relaunching your game to produce a new YAML
2. Running Archipelago generation again with the new YAML

### "ID conflict detected"

This can happen when playing with other games that use similar ID ranges. The framework will automatically remap conflicting IDs - no action needed.

### Connection Issues

Verify:
- The Archipelago server is running
- Your game is on the same network as the server
- The connection settings in `framework_config.json` are correct

## Advanced Configuration

### Custom Item Classifications

Items in your capabilities config can have these classifications:
- `progression`: Required to complete the game
- `useful`: Helpful but not required
- `filler`: Basic items to fill remaining slots
- `trap`: Negative effects (based on trap_item_chance)

### Multiple Instances

If your game has multiple instances of the same location (e.g., repeatable checks), the framework tracks instance counts automatically and generates unique names (e.g., "Shop Purchase #1", "Shop Purchase #2").
